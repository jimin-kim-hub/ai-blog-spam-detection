# 데이터마이닝 팀 프로젝트: AI 생성 블로그 스팸 탐지 및 문체 진화 분석

## 1. 프로젝트 개요 (Background & Necessity)
최근 생성형 AI(Generative AI)의 접근성이 크게 향상되면서, 네이버나 구글 같은 포털 사이트의 블로그 생태계에 **AI가 대량으로 자동 생성한 상업용 어뷰징 게시물이 급증**하고 있습니다. 이는 검색 엔진의 신뢰도를 떨어뜨리고 소비자들에게 잘못된 정보를 제공하는 심각한 현실 문제로 대두되고 있습니다.

초창기 생성형 AI의 텍스트는 부자연스러운 문맥과 뻔한 감성적 표현(예: "안녕하세요! 오늘은~")으로 인해 일반인도 쉽게 구별이 가능했습니다. 하지만 최근의 스패머들은 프롬프트 엔지니어링을 통해 **'건조한 정보성 문체'**나 **'인간 특유의 불완전성(단문, 띄어쓰기 생략 등)'**을 교묘하게 모방하는 **인간형 위장 AI**를 만들어내고 있습니다.

본 프로젝트는 이러한 배경에서 출발하여, **AI의 문체 위장 수준이 정교해짐에 따라 탐지 모델이 겪는 난이도 변화와 탐지 패턴의 이동**을 데이터마이닝 관점에서 심층 분석하고, 차세대 AI 탐지 시스템의 방향성을 제시합니다.

## 2. 분석 목적 (Objectives)
* 단순한 탐지 정확도(Accuracy 99% 달성 등)를 자랑하는 것이 목적이 아닙니다.
* **위장 수준 추적:** AI가 인간을 흉내 낼수록 모델이 사람으로 착각하여 발생하는 **미탐(False Negative) 급증 현상**을 정량적으로 규명합니다.
* **탐지 기제의 진화 증명:** AI가 발전함에 따라 모델의 탐지 기준이 단순한 '단어(TF-IDF)' 기반에서 보이지 않는 '문체/구조(Meta features)' 기반으로 어떻게 이동하는지 **SHAP(Explainable AI)** 기법으로 명확하게 해석합니다.

## 3. 데이터 및 실험 구조 (Data & Formulation)
프로젝트를 위해 총 1,200건의 블로그 본문 데이터를 자체 구축하였으며, 진화 단계별로 4가지 실험(Experiment) 환경을 설계하였습니다.

### 3.1. 데이터 구성
* **Human (600건):** 실제 인간이 작성한 자연스러운 맛집/리뷰 블로그 텍스트 원본.
* **AI_v1 (GPT형, 600건):** 기본 프롬프트로 생성된 친절하고 감성적이며 상투적인 전형적 AI 텍스트.
* **AI_v2 (인간형 위장, 300건):** 이모티콘 사용 금지, 건조한 문체 사용, 단문 위주의 작성 등 철저하게 인간을 모방하도록 프롬프트를 세밀하게 조작한 AI 텍스트.

### 3.2. 실험(Experiment) 설계
인터넷 생태계의 변화 흐름을 시뮬레이션하기 위해 다음과 같이 실험군을 나누었습니다.
* **`EXP1 (Human vs AI_v1)`:** 전형적인 1차원적 AI 탐지 환경 (탐지 난이도: 하)
* **`EXP2 (Human vs AI_v2)`:** 인간형 위장 AI 탐지 환경 (탐지 난이도: 중)
* **`EXP3 (Human vs AI_v1+v2)`:** 초보 스패머와 고도화된 스패머가 공존하는 **실제 인터넷 생태계 혼합 환경** (탐지 난이도: 상) - **🔥 본 프로젝트의 메인 분석 대상**
* **`AI_vs_AI (AI_v1 vs AI_v2)`:** AI 내부의 문체 진화 특성(정말 우리가 만든 AI_v2가 기존 AI와 문체적으로 다른가?)을 수학적으로 증명하기 위한 서브 검증 실험

## 4. 분석 파이프라인 (Methodology)

### 4.1. 텍스트 전처리 (Preprocessing)
정규표현식을 이용하여 불필요한 URL, 특수기호를 제거하고, `KoNLPy(Okt)`를 활용하여 한국어 형태소 분석을 수행하였습니다.

### 4.2. Feature Engineering 및 '길이 편향 방어'
* **길이 편향 방어 (Length Leakage Defense):** 모델이 단순히 '글의 길이' 차이로 정답을 유추하는 꼼수를 막기 위해 `char_count`(글자 수), `total_tokens` 등 직접적인 길이 피처를 원천 차단했습니다.
* **복합 피처 구성 (Combined Mode):** 
  - **TF-IDF (300차원):** 본문에서 주로 사용된 단어 빈도 기반 피처
  - **Meta Features:** `sentence_len_std`(문장 길이 분산), `verb_ratio`(동사 비율), `friendly_ending_count`(~해요, ~답니다 횟수) 등 문서의 **구조적 리듬**을 잡아내는 메타 피처 결합

### 4.3. 모델링 및 해석 (Modeling & Interpretation)
* 고차원 희소 행렬 처리와 비선형 패턴 학습에 강력한 **XGBoost Classifier**를 활용하였으며, 5-Fold Stratified CV로 검증했습니다.
* **SHAP(TreeExplainer)**을 도입하여 모델 판단의 블랙박스를 열고 피처 중요도 변천사를 추적했습니다.

## 5. 분석 결과 및 해석 (Results & Insights)
1. **탐지 난이도의 증가 (미탐 급증):** 
   * 초기 GPT형(EXP1)은 F1-score 0.99 이상으로 극히 쉽게 탐지되었습니다.
   * 그러나 인간형 AI가 섞인 혼합 생태계(EXP3)에서는 모델이 교묘하게 쓰인 AI 글을 인간으로 착각하는 **False Negative(미탐) 건수가 기하급수적으로 급증**하였습니다.
2. **문체 진화에 따른 탐지 패턴의 이동 (SHAP Transition):**
   * **과거:** EXP1에서는 `friendly_ending_count`(~해요, ~답니다)가 1순위 탐지 기준이었습니다.
   * **현재/미래:** AI가 위장술을 터득한 EXP3에서는 단순 말투 피처의 영향력이 하락하고, **`sentence_len_std`(문장 길이 분산) 같이 인간 고유의 불규칙한 문장 호흡을 잡아내는 구조적 메타 피처**가 새로운 핵심 탐지 기준으로 부상했습니다.

## 6. 기대 효과 및 한계점 (Impact & Limitations)
* **기대 효과:** 단순한 금칙어 기반 스팸 필터링은 곧 무력화됨을 증명하였으며, 앞으로의 방어 시스템은 텍스트의 '구조적 리듬'을 파악하는 방향으로 고도화되어야 함을 제시합니다.
* **한계점:** 1,200건의 데이터로 거대한 블로그 생태계를 완벽히 대변하기에는 규모적 한계가 존재하며, 원본 수집 과정에서 발생한 인간과 AI의 미세한 기본 길이 분포 차이를 완벽히 통제하기는 현실적으로 어렵습니다.
* **추후 개선 방안:** 띄어쓰기 오류, 고의적 오타까지 주입한 '초정밀 위장 AI' 연구 및 이미지/태그를 함께 분석하는 멀티모달(Multi-modal) 탐지 시스템으로의 확장이 필요합니다.

## How to Run (코드 실행 가이드)
본 프로젝트는 누구나 쉽게 결과를 재현하고 시각화할 수 있도록 완벽하게 세팅되어 있습니다.

### Step 1. 프로젝트 다운로드 (Clone)
```bash
git clone https://github.com/jimin-kim-hub/ai-blog-spam-detection.git
cd ai-blog-spam-detection/제출용_코드
```

### Step 2. 필수 라이브러리 설치
본 프로젝트는 형태소 분석 및 기계학습 모델링을 위해 아래의 패키지들을 사용합니다.
```bash
pip install pandas numpy scikit-learn xgboost shap matplotlib konlpy
```

### Step 3. 폴더 구조 확인
`제출용_코드` 폴더 내부에는 모델 학습용 코드인 `데마_최종_통합_파이프라인_고도화.ipynb`가 있으며, 데이터는 `dataset/` 폴더 내에 안전하게 보관되어 있습니다. 코드가 상대 경로로 묶여있어 파일을 따로 이동하실 필요가 없습니다.

### Step 4. 주피터 노트북 실행 및 모드 변경
주피터 노트북을 실행하신 뒤, 코드 최상단에 있는 `EXPERIMENT_NAME` 변수를 변경하여 원하는 실험 결과를 즉시 확인할 수 있습니다.
* `EXPERIMENT_NAME = "exp1"` : 전형적인 GPT형 AI 탐지 시뮬레이션
* `EXPERIMENT_NAME = "exp2"` : 인간형 위장 AI 탐지 시뮬레이션
* **`EXPERIMENT_NAME = "exp3"` : 실제 인터넷 혼합 생태계 시뮬레이션 ( 본 프로젝트의 메인 분석 결과를 보시려면 exp3로 설정하세요!)**
* `EXPERIMENT_NAME = "ai_vs_ai"` : AI 내부의 문체 진화 특성 증명 모드

원하는 모드로 설정 후 **[Run All (전체 실행)]**을 누르시면, 데이터 전처리부터 XGBoost 모델 학습, 성능 평가 표, 오탐/미탐 결과 분석, 그리고 대망의 SHAP 시각화 그래프까지 모두 자동으로 출력됩니다!
